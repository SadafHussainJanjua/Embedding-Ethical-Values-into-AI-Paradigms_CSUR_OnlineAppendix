This is the online appendix for the Systematic Mapping Study titled Integrating Ethical Values into AI Paradigms: A Systematic Mapping Study. It contains files with .xls extension, allowing you to view the files using Excel software. Inside, there are 5 different sheets:

Initial List of Papers: This excel sheet contains all initial list of papers retrieved from the execution of the query described in the paper from all 4 databases.

Duplicate Studies: This excel sheet contains all duplicate studies which were excluded from selected set of studies.

Evaluation Relevance: This excel file contains all studies with evaluation relevance of each based on prior 2 decisions leading to final decision.

Final List of Papers: This excel file contains the complete list of final included studies with descirption of their relevance.

Research Questions: 
This file shows the entire inclusion/exclusion process for the articles. It also includes the quality assessment process, as described in Section 3 of the paper.
The complete process for conducting the card sorting to obtain the taxonomy of technical issues.
The complete process for conducting the card sorting to obtain the taxonomy of social issues.

Images: A folder containing all the images shown in the paper to provide a better reading experience.
